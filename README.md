# RobotBattle

**ジャンル:** 3Dアクション  
**対応機種:** PC  
**プレイ人数:** 1人  

## 基本操作方法
※コントローラー推奨

| キー / ボタン | コントローラー | 動作 |
|---------------|----------------|------|
| W / ↑         | 左スティック上 | 前移動 |
| S / ↓         | 左スティック下 | 後移動 |
| A / ←         | 左スティック左 | 左移動 |
| D / →         | 左スティック右 | 右移動 |
| スペース      | Aボタン        | 動作 / 攻撃 |
| Shift         | Bボタン        | 戻る |
| X             | Xボタン        | メニュー |
| E             | RB             | カメラ回転 |
| Q             | LB             | カメラ回転 |
| エスケープ    | なし           | 終了 |
